# X1.6 工具升级需求清单

来源：Job_Knurl_New_01 焊头 `finial_2-5` 网格优化实战（2026-11-17 ~ 11-18）。
所有需求均对应实际踩过的坑，括号内为现场证据。

---

## 0. 背景与目标

- 当前状态：181 警告正选候选（`reports/cae_mesh_optimize_20261118_094958_74a82d83/apply/model_candidate.cae`）与 208 对照候选，**纯内部节点移动已到收益边界**——两条路线的累计最小体积比都压在 25% 下限（单元 19211 贴 25.0%），再动节点即触发体积保护。
- 警告分布：181 个警告中 **52% 集中在两条外缘**——Y≈-1.2 带 47 个、Y≈3.8 带 47 个（verify/worker_result.json 形心统计）；典型单元 18413、10828（Y≈-1.2）、17006（Y≈3.8）。
- 核心目标：**支持局部重划**这两条外缘带，在保留齿形、选区外网格和全部绑定的前提下消掉 ≥70 个警告，为后续数据检查和物理验证扫清障碍。

---

## 1. P0（必须）：局部重划能力

### 1.1 选区输入（至少支持三种）
- 按单元列表：`--elements "18413,10828,17006"` / `--elements-file list.txt`
- 按部件坐标包围盒：`--bbox "x0,y0,z0,x1,y1,z1"`
- 按已有集合/面名：`--nset/--elset/--surface`（必须能引用 CAE 内已有集合）
- 便捷语法（推荐）：`--boundary-plane "Y=-1.2" --band-width 1.0`（平面+带宽自动生成选区）

### 1.2 局部布种参数
- `--seed-size`：选区内目标单元尺寸（mm）
- `--bias`：向选区内部的偏置比（控制过渡）
- `--min-size`：碎边守卫（默认 0.05mm，低于即拒绝生成）
- **选区外一切种子保持不动**（这是与 mesh-study 整件试划的本质区别）

### 1.3 拓扑与几何保留（硬约束）
- 选区外单元连接**逐单元逐节点完全一致**（可用哈希校验）
- 齿形轮廓不变：只允许"边布种变化 + 选区内网格重生"，禁止移动几何点/面
- 选区界面无悬挂节点（重划区与保留区共享节点必须协调）
- 单元类型保持 C3D4T（可选 `--element-type` 显式指定）
- 禁止混合单元类型进入选区

### 1.4 实现路径建议
- 在副本上：按选区生成 partition/imprint → 仅删除选区单元 → 局部布种 → 局部自由四面体重划 → 界面节点匹配校验。
- 若 CAE 内核不支持局部重划，**明确报"缺少 XX 能力"并停止**，不允许整件重划冒充局部结果。

## 2. P0：体积/累计检查改进

1. **体积检查失败必须输出失败明细**：单元 label、原体积、新体积、比值、连带节点。（现状只有"候选单元体积检查失败"一句，现场是手工用 NumPy 复算才定位到 19211/390/412——工具应直接给出。）
2. **新拓扑的基准策略**：重划区新生单元没有"原体积"，需显式规则：
   - `--volume-baseline region|global|none`；重划区建议以"重划前区域总体积分布"为新基准；
   - 跨拓扑链条累计检查时，工具自动检测拓扑已变并按新基准处理。
3. `--min-volume-ratio` 可配置（默认 0.25 保留；25% 是工具自设安全线而非 Abaqus 判废标准，需在文档注明）。
4. 分区统计：选区内/选区外的体积比、警告数**分开报告**。

---

## 3. P0：绑定与语义保护校验（重划后自动跑）

逐项核对并输出"通过/未知/失败"：

- 接触面完整性：`oner_1`/`oner_2`/`oner_3`、`m_Surf-11` 等的面片数与面积变化（本模型 `oner_1` 同时喂通用接触和 VUAMP 的 `SENSOR_HORNCONTAC`，`Job_Knurl_New_01.inp:66663-66665`）；
- 刚体约束与参考点：`*Rigid Body` 的 ref node、elset 覆盖数（`INP:66465-66466`）；
- 关键集合：Set-4/Set-5/Set-8 等被载荷/边界/传感器引用的集合存在且元素数合理；
- 历史输出（`*Output, history, sensor`）引用的面/集完整；
- 内部节点载荷、`*Tie` 等约束引用（X1.4 已声明此项未知，`X1.4_使用说明.md:24`，应升级为自动核对）。

## 4. P1：质量与报告增强

1. **警告聚类报告**：mesh-audit 输出 CSV——label、形心（部件坐标）、最小二面角、外接球质量、所属面/边、聚类标签（如"Y≈-1.2 外缘带"）。
2. **分区质量统计**：试划区 vs 区外的警告数、错误数、最小二面角、体积比、稳定增量最差单元定位。
3. **官方/独立双口径警告数并列**（现场两种口径都用：210 vs 180、253 vs 251）。
4. 稳定时间增量：给出 worst 的**单元定位**，不只是数值。
5. 报告语言中文；数据结论附**文件路径 + JSON 字段路径/行号**（项目规范）。
6. "完成 ≠ 分析通过/物理正确"的免责声明保留。

---

## 5. P1：批处理与链式运行

1. 文档写明 `--passes` 语义（X1.5 现状：无改善即拒发候选并停，`worker_cae_apply.py:73`；实测一轮即收敛到历史行为）。
2. `--baseline <caE/网格记录>` 显式指定累计基准，支持跨拓扑链条与"独立对照路线"（本次 450 路线以自身为基准的用法应文档化）。
3. 批次状态文件 + 中断续跑。
4. 自动产出**新旧候选对照表**（警告数/错误数/稳定增量/体积比/趋势），即"警告更少但增量更小"的取舍判断支持。

## 6. P2（可选）：几何级增强

1. **虚拟拓扑自动化**：合并 <0.1mm 短边/碎面，只合并不改齿形棱线（齿尖碎面是 2593°C 温度飞点的根源）。
2. 旧四面体算法开关：mesh-study 实测旧算法 450 警告 vs 基准 527（`X1.4_验收记录.md:9`），应作为 `--tet-algorithm` 选项固化。
3. 规则区六面体试划（齿身 sweep）+ 单元类型对照。
4. mesh-study 支持**局部**变体（与 1.1 选区联动）。
5. 重划前警告消除量预估。

## 7. 稳健性与环境

1. 启动自检：numpy/scipy 依赖、Abaqus 许可证、路径存在性；缺依赖给明确报错（现场踩过 `ModuleNotFoundError: numpy`，装 numpy 2.5.5 + scipy 1.18.1 后正常）。
2. 已知 Abaqus 退出码 `3221226505 (0XC0000409)`：识别为"进程异常退出但数据可能完整"，以**重开候选后的复核结果为准**，自动重开校验并注明，不误报整体失败。
3. 日志/报错编码统一 UTF-8（现场 stderr 出现 GBK 乱码：`官方警告未减少` 变 `�ٷ�����δ���٣�`）。
4. `结果.json` 字段稳定可机读（`official_before/after`、`min_volume_ratio`、`stable_time.worst`、`official_new_warnings`、`candidate` 等沿用现有命名）。
5. 退出码语义化：0 成功发布 / 2 无改善 / 3 保护检查失败 / 4 环境问题。

## 8. 测试与验收

1. 既有自动化回归保持全绿（X1.4 末 53 项）。
2. 新增用例：
   - 局部重划后选区外网格逐节点一致（哈希级）；
   - 界面悬挂节点 = 0；
   - 体积检查失败输出明细；
   - 绑定校验（接触面/集合/传感器）通过与失败两个方向；
   - 跨拓扑基准切换。
3. **真实验收场景（本项目提供）**：
   - 输入：181 候选；选区：Y≈-1.2、Y≈3.8 两条外缘带（各宽约 1 个齿距）；
   - 参数：种子 0.15–0.25mm、min-size 0.05mm、偏置过渡 2:1 内；
   - 通过标准：选区外警告逐条不变；选区内警告降 ≥70%；0 新增错误；绑定校验全通过；稳定增量不低于现役 1.255e-9 s 的一半；累计体积检查按新基准通过。
