# X1.4 网格能力与验证状态

X1.4 沿用 X1.3 的统一入口 `x1.py` 和已有功能，不创建另一套助手。它面向网格问题的取证、候选试验和保护检查。程序不启动 Abaqus 数据检查或求解作业，不覆盖原始 CAE、INP、DAT、ODB 或求解日志；输出只能放在源文件所在目录之外。所有报告中的“完成”仅表示该程序步骤完成，不等同于分析通过或物理正确。

## 已实现的能力

1. `mesh-audit`：读取用户指定的已保存 INP、DAT 和目标部件，逐项映射实例、单元编号、源文件行号、部件局部坐标和 Abaqus 原始质量数据；独立计算 C3D4/C3D4T 的体积、边长、外接球质量和内部二面角，并按共享面分组。纯四面体目标部件额外标识网格外露边界节点。其余类型只映射 DAT 条目；不完整或未识别内容列为未知。
2. `mesh-optimize`：对纯 C3D4/C3D4T 的单实例部件，在独立 INP 候选上尝试移动内部节点；固定网格外露边界节点和单元连接，逐节点检查相邻单元的体积方向及自算警告，严禁新增自算超限，写出精度再复查。默认三轮、每轮至多 2000 个节点；可调整为最多五十轮。输出候选、哈希、移动节点和报告；没有改善则不输出候选。无需 Abaqus/CAE 许可证，需 NumPy 和 SciPy。
3. `mesh-study`：从同一已保存 CAE 的独立副本逐个试验基准、整体种子尺寸两种比例、关闭映射面网格、四面体另一算法。每个方案从原始副本开始；记录 Abaqus 网格检查、稳定增量估计、集合和区域数量。仅在无网格改变的基准可读取后继续。任何候选都需要另外复核实体边界、集合和接触语义；数量一致不代表绑定关系已验证。
4. `mesh-compare`：重新读取原 INP 和输出候选，检查目标部件连接、外露边界节点、单元体积方向、原始输入其他文本和实例定义是否改变，并复算警告。该命令随候选生成自动运行，也可单独调用。
5. `cae-mesh-optimize`：读取已保存 CAE 的副本，经 Abaqus 原生网格检查导出四面体，固定外露边界优化内部节点；在另一副本中修改节点，并使用 Abaqus 检查。如出现新增警告，则回退相关节点，再检查；保存后重新读取核对外边界、单元连接、体积方向和官方警告。不会自动提交作业或替换原模型。内部面、内部节点载荷与集合仍需人工核对。

## 使用

```powershell
python x1.py mesh-audit --inp "D:\AbaqusTest\Job_Knurl_New_01.inp" --dat "D:\AbaqusTest\Job_Knurl_New_01.dat" --part finial_2-5 --output-dir "D:\EngineeringAgent\reports"
python x1.py mesh-optimize --inp "D:\AbaqusTest\Job_Knurl_New_01.inp" --dat "D:\AbaqusTest\Job_Knurl_New_01.dat" --part finial_2-5 --max-nodes 2000 --passes 5 --output-dir "D:\EngineeringAgent\reports"
python x1.py mesh-study --cae "C:\Users\Jinshuo\Desktop\simulation_model\horn_knurl\finial_2.cae" --model Model-1 --part finial_2-5 --abaqus "D:\Program Files\SIMULIA\Commands\abaqus.bat" --output-dir "D:\EngineeringAgent\reports"
python x1.py cae-mesh-optimize --cae "C:\Users\Jinshuo\Desktop\simulation_model\horn_knurl\finial_2.cae" --model Model-1 --part finial_2-5 --abaqus "D:\Program Files\SIMULIA\Commands\abaqus.bat" --output-dir "D:\EngineeringAgent\reports"
```

INP/DAT 文件配对必须人工确认。`mesh-optimize` 会对目标实例全部 DAT 警告行复算数值、检查调整标记及完整警告集合；即使通过，也只代表几何信息一致，不证明两个文件来自同一执行过程。`INCLUDE`、多实例部件、混合单元、缺失节点、节点调整或质量表不匹配时拒绝优化。重叠、非流形以外的几何交叠、时间增量、温度、接触、内部节点集以及求解稳定性需另行复核。

实验性 INP 候选不更新 CAE；应先由用户确认并操作 Abaqus 数据检查，再复核接触面、区域定义和热力结果，方可决定是否用于分析。当前算法只调整内部节点，不生成全新的六面体或四面体拓扑，也不做齿形简化或几何分区；不承诺警告清零。

`mesh-study` 已在已保存的真实 CAE 副本上运行五种网格对照；受限后台返回 `FlexNet -63,403`，获得许可的运行环境可正常使用 CAE 内核。基准失败时停止后续试划并写明错误。历史模型、用户当前打开会话及其未保存修改保持隔离。详情见 `X1.4_验收记录.md`。
