# X1.3 通用前处理使用说明

统一入口 `python x1.py`。材料、单位、接触参数和出处由项目提供；所有 INP 修改输出到独立目录，输出前检查目标对象之外的原始内容是否逐字节相同，并记录原始文件、参数文件、输出文件及对象外内容的 SHA-256。程序不修改 CAE、不做数据检查、不启动作业。副本 INP 不会自动同步到 CAE。

## 材料参数写入

```powershell
python x1.py thermal-material-write --inp 输入.inp --spec 材料.json --output-dir 独立输出目录
```

JSON 必须提供 `material`、`unit_system`、`source`、`properties`。以下是结构说明：尖括号表示必须由用户替换的值。`rows` 每行是数字数组，温度相关表最后一列为温度，必须递增；未列出的属性原样保留。

```json
{
  "material": "<材料名>",
  "unit_system": "<经确认的单位制及温标>",
  "source": "<参数来源及版本>",
  "properties": {
    "density": {"rows": [["<密度>"]]},
    "elastic": {"rows": [["<弹性模量>", "<泊松比>", "<温度>"]]},
    "conductivity": {"rows": [["<导热率>", "<温度>"]]},
    "specific_heat": {"rows": [["<比热>", "<温度>"]]},
    "expansion": {"zero": "<参考温度>", "rows": [["<膨胀系数>", "<温度>"]]},
    "plastic_johnson_cook": {"rows": [["<A>", "<B>", "<n>", "<m>", "<熔化温度>", "<转变温度>"]]},
    "rate_johnson_cook": {"rows": [["<C>", "<参考应变率>"]]},
    "inelastic_heat_fraction": {"rows": [["<转热比例>"]]}
  }
}
```

各向同性常数弹性为 `[E, 泊松比]`，温度表为 `[E, 泊松比, 温度]`；密度、导热率、比热、膨胀系数的常数为单列，温度表为 `[数值, 温度]`。当前仅支持单行六参数 JC 塑性、单行两参数 JC 应变率及常数非弹性热份额。其他材料属性原样保留；现有对应卡片含附加选项、同名卡重复或模型类型不同时拒绝自动覆盖。JSON 中应使用实际数字，不能保留尖括号字符串；需先按模型单位制换算，程序不会自动推断换算。

## Excel 转材料 JSON

```powershell
python x1.py material-excel-spec --xlsx 材料表.xlsx --mapping 单元格映射.json --output-dir 独立输出目录
```

映射 JSON 的 `material`、`unit_system`、`source` 与上节相同；`properties` 内每项写 `{"sheet":"工作表名称","range":"A2:B5"}`，热膨胀可额外写 `zero`。区域只包含数值，列顺序遵循上一节。工具仅读取用户明确指定的区域和已缓存数值，不自行识别表头、转换单位或补值；空值、文本和未缓存公式会报错。生成的 `material_spec.json` 再交给 `thermal-material-write`。Excel 转换需要 `openpyxl`。

## 接触属性副本编辑

```powershell
python x1.py interaction-edit --inp 输入.inp --spec 接触.json --output-dir 独立输出目录
```

JSON 必须提供 `interaction`、`unit_system`、`source` 和 `changes`。`changes` 仅写要改变的属性：`friction`（无量纲常数）、`heat_conversion`（耗散转热比例）、`secondary_fraction`（分配到次表面的比例）、`gap_conductance`（`dependency` 为 `pressure` 或 `clearance`，`rows` 各行为 `[导热系数, 压力或间隙]`，可选第三列温度）。所有值和数据来源均需显式提供。新建生热卡时须同时提供两个比例。

常数摩擦及标准生热卡可修改；复杂参数化摩擦、同名卡重复或不支持的附加选项会拒绝覆盖。改变接触导热表会改变默认导热行为；热分配须结合主次面或通用接触角色核对。

## 输入文件对照和截面核查

```powershell
python x1.py inp-diff --before 原文件.inp --after 修改后.inp
python x1.py thermal-audit --inp 输入.inp
```

`inp-diff` 输出按关键词卡片的变化和源行号、文件哈希、原始内容是否相同；比较规范化了关键词、参数和数字格式，忽略注释。它是卡片级对比，不涵盖所有 Abaqus 语义；出现 INCLUDE 时标记不完整，不展开引用文件。编辑命令同时生成逐行 diff、对象外内容哈希和中文报告。

`thermal-audit` 的 `sections` 列出已识别的零件级实体截面、材料、单元类型和数量、显式 section controls 与来源行号。未显式设置时写明“按默认规则核查”，不等同于没有沙漏控制；不支持的单元、集合和装配级映射标为不完整。编辑含 INCLUDE 的输入目前拒绝执行，避免生成不完整副本。

## 验证和权限

项目中 `tests` 包含原有及新增测试。系统 Python 命令：

```powershell
$env:TEMP='D:\EngineeringAgent\test_tmp'
$env:TMP='D:\EngineeringAgent\test_tmp'
python -m unittest discover -s tests -q
```

读取并修改副本需由用户明确指定输入及参数，结果仍需查看报告和数据检查。工具不替用户作物理参数标定；不识别的不推定通过。
