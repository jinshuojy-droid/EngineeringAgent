# X1.6 网格前处理使用说明

在 `D:\EngineeringAgent\x1_1_development` 中通过 `python x1.py` 使用统一入口。局部重划使用 Abaqus/CAE 内核和 CAE 许可证。独立网格统计使用当前 Python 环境的 NumPy 和 SciPy。长度、坐标和面积沿用输入模型的单位。本文焊头案例用 mm、mm² 和 s。

## 定位现有警告

```powershell
python x1.py cae-mesh-locate --export 'D:\EngineeringAgent\reports\cae_mesh_optimize_20261118_094958_74a82d83\verify\worker_result.json' --boundary-plane 'Y=-1.2' --boundary-plane 'Y=3.8' --band-width 1.0 --job Job_Knurl_New_01 --output-dir 'D:\EngineeringAgent\reports'
```

`--export` 接受官方网格复核导出的 JSON。可重复指定 `--boundary-plane`。`--band-width` 是以平面为中心的总宽，分带按形心判定，重叠的分带可重复计数。CSV 列出单元、形心、二面角、外接球质量、体积和固定边界节点数。

## 预览和探测

```powershell
$abaqusPath = 'D:\Program Files\SIMULIA\Commands\abaqus.bat'
$hornPath = 'D:\EngineeringAgent\reports\cae_mesh_optimize_20261118_094958_74a82d83\apply\model_candidate.cae'
python x1.py cae-mesh-local --cae $hornPath --model Model-1 --part finial_2-5 --abaqus $abaqusPath --bbox '16,-1.7,-1.7,22,-0.7,-0.9' --partition-probe 'Z=-1.7' --preview --output-dir 'D:\EngineeringAgent\reports'
```

选区参数从 `--elements`、`--elements-file`、`--bbox`、`--nset`、`--elset`、`--surface` 和 `--boundary-plane` 中选一种。单元列表用逗号或空白分隔。坐标盒顺序是 `xmin,ymin,zmin,xmax,ymax,zmax`，按部件坐标和形心选单元。命名区域使用 CAE 中的部件或装配实体，重名时会提示改用其他选区方式。节点集选中与节点相连的单元。

`--partition-probe` 在独立副本内存中尝试一次轴向平面分区，记录分区数量和失去原编号的区外单元。预览报告同时列出请求范围和 Abaqus 可以独立重划的实体范围。工具从已有独立实体分区起跑，整件被命中时立即停止。探测副本仅用于诊断分区影响。

## 在已有独立实体分区上试划

```powershell
$fixturePath = 'D:\EngineeringAgent\reports\x16_fixture_20261118_110202\partitioned_fixture.cae'
python x1.py cae-mesh-local --cae $fixturePath --model Model-1 --part Block --elset Right --seed-size 0.32 0.38 --min-size 0.05 --abaqus $abaqusPath --output-dir 'D:\EngineeringAgent\reports'
```

每个 `--seed-size` 用原始输入的独立副本进行一次对照。`--bias 2 --bias-toward Y=low` 指定偏置和细端方向。`--tet-algorithm keep|default|legacy` 控制试划区的四面体算法。`--min-size` 为新网格最短边检查下限。`--min-step` 控制官方网格稳定时间增量估计的下限。`--min-warning-reduction 0.70` 要求试划区警告下降至少 70%。`--accept-cell-expansion` 允许按预览中的实际独立实体区执行，原请求和实际范围都会保留。`--resume` 指向之前的试验目录，原参数和输入哈希须一致，已有完整对照结果可复用。

复核重开保存的独立副本，要求区外节点坐标、编号、单元连接及布种证据一致，区外警告标签一致。用共享三角面和 Abaqus 不兼容界面检查核对交界，同时报告物理网格一致性和编号一致性。编号发生变化的副本保留为试验记录。工具还对照可读的集合、表面和引用，关键引用未知时保护检查失败。

跨拓扑以同一实体区为体积比较单元。报告含总体积、分位数、最差角和最短边，现有总体积差保护线为 0.5%。`--passes` 只用于 `cae-mesh-optimize`，表示每批内部节点优化的最大遍数。官方警告没有严格下降时不发布平滑候选。其累计单元体积默认保护线为原体积 25%。可以用 `--baseline` 指定同一连接的网格导出 JSON。失败单元的编号、涉及节点和体积见 `volume_failures` 或回退历史。将重划后的网格作为新的优化输入时，使用新连接的网格作为该条路线起点。

## 状态和证据

- `cae-mesh-local` 返回 `0` 表示预览完成或候选发布，具体见 `candidate`。`2` 表示网格改善未达门槛。`3` 表示保护检查失败或缺少独立实体区。`4` 表示内核或环境故障。
- `结果.json` 记录试验参数、初始 SHA-256、候选路径、网格统计和各阶段日志位置。已知进程异常退出码仅在完整结果与独立重开核验充分时才继续。后台保留原始字节和转码后的 UTF-8 文本。
- 工具结果属于网格及前处理验证。作业数据检查、求解和物理结果属于后续验收。
